## Work Projects

### [Bread Checks — Excel Data Validation & Import Pipeline](Work/Bread)

A Python-based ETL pipeline for processing, validating, and importing product catalogues from Excel files into MS SQL Server.

**Key features:**
- Reading Excel files using pandas and python-calamine.
- Data validation, including data types, required fields, and duplicate detection.
- Data processing and transformation using pandas and NumPy.
- Loading validated data into MS SQL Server using SQLAlchemy and pyodbc.

**Technologies:** Python, pandas, NumPy, SQLAlchemy, pyodbc, MS SQL Server, Jupyter Notebook.
